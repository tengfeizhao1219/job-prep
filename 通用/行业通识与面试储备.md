## 一、AI / 大模型(JD2 智谱·关键短板,务必补)

### 1. 大模型是什么(用 30 秒讲清)
- 基于 Transformer 的**生成式模型**,海量语料预训练 → 具备语言理解/生成能力
- 关键概念:**预训练(Pre-train)→ 微调(SFT/RLHF)→ 推理(Inference)**;上下文窗口(Context)、Token、幻觉(Hallucination)
- 主流技术路径:通用大模型(基座) vs 垂直/行业大模型;Agent(智能体)让模型能调工具、自主完成任务

### 2. 主流大模型厂商 & 各自优劣(JD2 明确要求"了解主流大模型厂商优劣")
| 厂商/模型 | 特点 | 定位 |
|---|---|---|
| **智谱 GLM**(智谱本就是这家!) | 国产头部、全自研、To-B 政企切入深、Agent 生态 | 央企/政企首选,招聘方 |
| DeepSeek | 开源 + 极致性价比/推理强 | 技术圈极热,成本优 |
| 通义千问(阿里) | 云生态 + 企业服务全 | 阿里云生态 |
| 豆包(字节) | 消费级 + Agent 应用强 | 应用层活跃 |
| 文心(百度) | 中文强、政企沉淀 | 传统厂商 |
| 智谱/月之暗面 Kimi | 长上下文章 | — |
| 海外:GPT/Claude/Gemini | 综合最强 | 对标 |

### 3. Agent(智能体)是什么(智谱重点)
- **Agent = 大模型 + 规划 + 工具调用 + 记忆**,能自主完成任务而非单轮问答
- 典型:多智能体协作、RAG(检索增强)、Function Calling、Workflow
- To-B 落地常结合"大模型 + 知识库/RAG + 业务系统"做智能客服/知识问答/数字员工/文档处理

### 4. To-B AI 交付的典型形态(JD2 要的)
- **智能客服/坐席辅助**:电力/金融/运营商客服场景
- **知识问答/企业知识库**:RAG,政企文档
- **数字员工/流程自动化**:金融审批、公文处理
- **垂直行业大模型**:法律/医疗/能源
- 交付难点:数据质量、算力成本、效果调优(幻觉)、**验收标准**(效果如何量化)、与既有系统集成

### 5. 智谱这家公司(投它要知道)
- 估值 4000 亿、全自研 GLM、To-B 政企深、口号「Think Big, Deliver Solid, Scale Stable」
- 已拿 9390 万大单;To-B 定制项目(电力/金融/运营商/能源)

## 二、自动驾驶(JD1 博世·行业 gap,可作为跨界加分)

### 1. ADAS / 自动驾驶分级(L0-L5)
- **L1 辅助**、**L2 部分自动化(车道保持+ACC)**、**L3 有条件自动化(可脱手需接管)**、L4 高度自动、L5 全自动
- 博世等 Tier1 主要做 **L2/L2+ 的量产**(中阶智驾),这也是"泊车/行车"的范围

### 2. 泊车/行车两大域(JD1 直接相关)
- **泊车(APA 自动泊车 / AVP 代客泊车)**:超声波/摄像头融合感知 → 路径规划 → 控制;AVP 是停车场无人代客泊车(高价值场景)
- **行车(ADAS/NOA 领航辅助)**:车道保持、ACC、变道、NOA 高速/城区领航;感知→决策→控制
- 关键:传感器(摄像头/雷达/激光雷达/超声波)、域控制器(硬件 **ECU**)、软件/算法、OTA 升级

### 3. 博世苏州智能驾控(投它要知道)
- 博世智能驾控中国区产业创新项目落户苏州,**总投资约 100 亿**
- 已量产「**可适配燃油车型的中阶智能辅助驾驶方案**」(全国首款)
- 做自动泊车、智能驾驶辅助(ADAS)、底盘/传感器标定;客户 = 各大主机厂(OEM)
- 博世是 **Tier1(一级供应商)**,项目是**面向 OEM 客户的交付**(这正是 JD1 客户 PM 的语境)

### 4. 跨界话术(若投 JD1)
"我虽是金融/支付领域的大型交付背景,但项目管理方法论(跨硬件软件团队的集成、里程碑、质量、客户协同)完全可迁移;且我是计算机科班,对感知/域控/软件集成有技术认知,学习自动驾驶系统快。"——尽量展示**可迁移性 + 学习力**,别硬编造汽车经验。
