# 11 · 面试日速查 · 反问与必背弹药

> **用途**：面试现场 / 进门前手机速开本页。完整版见 [10-模拟面试复盘](10-模拟面试复盘·修正答案.html)（逐题最终版答案）、[09-概念串讲](09-核心概念串讲.html)（术语）。

---

## 🎤 反问环节（两主一备，至少问两个）

### 主问 1 · 先问（痛点切入型）

> "您在交付这条线带了这么久，我想请教一下——**这半年团队在交付侧最头疼的一两个问题是什么？**是产能、质量，还是客户侧的？"

- **为什么问**：他答什么，哪里就是你的切入点；展示你是冲着解决问题来的
- **听完怎么接**（把反问变成展示）：他说**质量** → 接同盾验收/质量体系经验；说**产能/积压** → 接迪士尼中台降本提效；说**客户侧** → 接海外客户干系人管理

### 主问 2 · 最后问（成功标准型，收口用）

> "**如果我入职，前 6 个月，这个岗位做到什么程度，您会觉得招对了人？**"

- **为什么问**：拿到他亲口说的成功标准；暗示你是来把事做成的人
- **他答完立刻接**：

> "明白，跟我想的对得上——我有些想法，比如接手后前 30 天先摸产能和质量基线再动体系，希望有机会展开。"

### 备用（想深挖管理半径时）

> "交付团队现在的构成，采集、标注、质检是自有还是外包混合？这个岗位管多大跨度？"

**不问**：薪资福利 / 加班 / 五险一金（留给 HR）；"公司未来战略"（太空）。

## 🧨 必背弹药

### 弹药 1 · 第一周盯什么数字（送分题）

**两率一差一记录**：

1. **废批率**——按场景/设备/班组拆开看，生产端生死线
2. **真值准确率**——质量端生死线，客户验收核心
3. **采集速度 − 加工速度的差值**——正差在涨 = 积压在涨，SLA 迟早爆
4. **近 3 个月 SLA 违约和客户投诉记录**

**三个危险信号**：

- 废批率**突然升高且集中在某台设备/某班组** → 设备漂移或培训问题
- 真值准确率**缓慢下滑**（不是骤降）→ 规范漂移或新人混入，最隐蔽
- 周产能达标但**一次通过率在降** → 在凑量，后患在后头

### 弹药 2 · 事故处理三步：**止损 → 定范围 → 主动通报**

第一反应问三个问题：这批**交付了没有**？**影响范围多大**？**同源工序还在产吗**？→ 立刻**冻结批次出库** → 15 分钟拆数据定位 → **主动给客户口径**（"发现 X 问题，已冻结，修复计划周三前给您"）。信任靠透明+方案保住，不靠悄悄修好。

### 弹药 3 · 客户加急：**接诉求 → 给「先行 30%」选项 → 调产不伤其他项目**

整单提前做不到，反提方案："已达标的部分先交 30% 解燃眉之急，整批日期不变"——给选项，不给死话。

## 📖 概念速记（一行版）

| 词 | 一句话 |
|---|---|
| 具身智能 | 让 AI 有身体、在物理世界干活 |
| 无本体数据 | 不带机器人本体的「人类怎么干活」数据——简智核心产品 |
| VLA | 机器人的大模型：看图+听指令→出动作；要海量人类操作数据当教材 |
| CoT | 数据里带「人当时怎么想」的推理步骤——学因果不死记动作 |
| 真值 GT | 数据的「标准答案」：位姿/手部/分段/成败；答案错=模型学坏 |
| DFM | 简智的数据基础模型：自动算真值，人工抽检+裁边界 |
| 时空同步 | 多条数据流对齐 1ms 级 + 多机位标定统一坐标系；硬件级护城河，报废头号原因 |
| 数据飞轮 | 数据→模型→真机评测→反馈→更多数据（Momenta 基因） |
| 流水线 | 数采→真值→CoT→DFM→质检→交付 |

**客户三类**：VLA 模型公司要「CoT+触觉」操作数据；世界模型公司要「多视角 Ego+状态」成对数据；本体厂商要「适配数据+真机评测」。
