## 三、术语表(听懂面试官黑话)

| 术语 | 意思 |
|---|---|
| 具身智能 | 有身体的 AI——机器人通过身体与环境交互来学习 |
| 世界模型 | 让 AI 预测物理世界怎么变化的模型(机器人预训练用) |
| 本体 | 机器人的身体;**无本体数据**=采自真人、不绑定机器人型号的数据 |
| Gen DAS | 简智可穿戴数采硬件:Ego(头戴视角)+ Fingers(仿生双指)+ Gripper(仿生夹爪) |
| GenADP | 简智数据生产线,采集后 2 小时出高质量加工数据 |
| Gen Matrix | 简智数据治理平台,采集→清洗→标注→评估全流程自动化 |
| DFM | Data Foundation Model,数据基础模型;自动生成真值(6D 位姿/触觉/手部跟踪/CoT/全身 Mesh) |
| 真值 / GT | Ground Truth,数据的"标准答案" |
| 6D 位姿 | 物体三维位置(x,y,z)+ 三维朝向(俯仰/偏航/翻滚) |
| 思维链 CoT | Chain of Thought——数据里带上"人当时怎么想的"推理过程(数采员边干边口述:看到杯子→挪开挡路的盘子→握杯身→放架子)。让模型学**因果决策**而不是死记动作,泛化才好;类比教材里的"解题步骤" |
| VLA | Vision-Language-Action,机器人界的大模型:输入画面+语言指令,直接输出动作。像 ChatGPT 读整个互联网学说话,VLA 靠海量人类操作数据预训练学"干活"——简智数据的核心买方用途 |
| 动捕 | 光学动作捕捉,记录高精度动作细节 |
| 时间同步 | 头/手/眼多路传感器在时间轴上对齐,简智做到 1ms 级 |
| 数据飞轮 | 数据→模型→客户→反馈→更多数据的增强闭环(CEO 的 Momenta 老本行) |
| SLA | 对客户承诺的服务标准:数据量/质量阈值/时间节点 |
| SOP | 标准作业程序,让换人换场地质量不掉 |
| 一次通过率 | 交付数据不经返工直接通过客户验收的比例——体系水平的核心指标 |
| 样批确认 | 大批量前先交小样批让客户确认规格,避免整批返工 |
| 真机评测 | 客户模型在真实机器人上实测,效果回流指导下一轮采集 |

## 四、流水线快记 6 条

1. **数采**:数采员穿 DAS,在模拟真实场景(家居/商超/工业/仓储/医疗)按脚本做操作,采多模态数据(视频/深度/轨迹/触觉/声音)
2. **清洗**:多传感器 1ms 同步、剔废、格式标准化;废品率是成本命门
3. **标注**:DFM 自动生成真值+人工校验兜底;规范一致性>单点准确率
4. **质检**:三级质检(自检/互检/专检)+ 不合格闭环(原因归类进 SOP)
5. **交付**:SLA 三要素(量/质/时)+ 样批确认再批量
6. **闭环**:真机评测回流→反馈下一轮采集(数据飞轮)

## 六、可能被问 + 一句话应答

| 问题 | 应答要点 |
|---|---|
| 你做过数据生产/交付吗? | 迪士尼数据中台:4 业务线模块化、10 报表、提速 2h、省 300 万、人力省 50% |
| 怎么从 0 到 1 搭交付体系? | 跟产线摸实情→立规范(SOP/质检/SLA)→试点→指标对比→横向复制(讲 90 天计划) |
| 数据质量怎么把控? | 三级质检+四项指标(准确率/完整性/一致性/规格)+不合格闭环进 SOP |
| 多项目并行怎么管? | SLA 优先级排产+瓶颈识别(设备/场地/人力)+里程碑周报+变更管理(举同盾/迪士尼例) |
| 没做过数采标注? | 坦承+迁移逻辑(非标生产标准化)+90 天补场景手感(见 04 文档话术) |
| 客户中途改需求? | 影响评估→变更方案+时间表→样批确认再批量(举真实变更案例) |
| 为什么离开上一家/为什么选简智? | 方向认同:具身智能是确定趋势,简智是无本体数据头部+数据闭环信仰;我的体系能力正好接公司扩张期"订单爆发、体系缺位"的阶段 |

## 七、反问环节(挑 2-3 个问)

1. 目前交付团队规模和构成?采集/标注/质检是自有还是外包混合?(听管理跨度)
