## 二、商业模式:卖什么、卖给谁

**一句话:机器人公司造"机器人",简智给机器人生产"教材"——人类操作数据。**

- **客户**:具身智能/世界模型公司(训练机器人模型的团队),部分也是股东(星海图、九识)
- **产品**:标准化、规模化生产的人类技能数据 + 数据生产基础设施(硬件+平台+产线)
- **不做什么**:不造机器人本体,不做机器人大脑——纯上游数据基础设施

产业链位置:

```
【上游】            【简智在这里】                          【下游】
传感器/硬件供应链 → 数据采集硬件 → 数据生产流水线 → 标准化数据交付 → 机器人/具身智能公司
                              (人+场地+平台+模型)            (星海图、九识、智元类客户)
```

---

## 三、核心路线:"无本体数据"

**"本体" = 机器人身体。** 行业采数据有两条路线:

| 路线 | 做法 | 问题 |
|---|---|---|
| 绑本体采集 | 用真机器人遥操作/示教采数据 | 一台数据只适配一类机器人,产线随机器人型号走,贵且慢 |
| **无本体采集(简智)** | 真人穿戴可穿戴设备干活,采"人类技能" | 数据不绑定任何机器人,一套数据服务所有客户 |

无本体数据的价值:**一套人类技能数据 → 可喂给各种机器人模型预训练** → 规模化、边际成本低。投资界报道已验证:有客户全部基于简智无本体数据完成预训练的新一代具身模型,在复杂操作泛化测试中表现出稳定的跨场景迁移能力——初步验证了无本体数据在预训练阶段的 scaling law。

## 四、业务飞轮:数据闭环

CEO 陈建兴在 Momenta 干的就是"数据飞轮",简智整个商业模式是这个逻辑的机器人版:

```
真人穿戴 DAS 设备采集 → GenADP 产线加工(2小时出成品) → DFM 生成真值/标注
        ↑                                                      ↓
反馈指导下一轮采集 ← 客户真机评测效果回流 ← 数据交付给客户训练模型
```

**面试语言**:简智骨子里信"数据驱动模型"——数据越多→模型越好→客户越多/规格越高→反哺采集策略→更多更好的数据。交付经理的职责就是让这个飞轮里的"生产环节"转得又快又稳。

## 六、这个公司处在什么阶段(对交付经理意味着什么)

- **一年 7 轮融资 + 万台设备订单** = 订单爆发、产能猛扩,交付端必然是"多项目并行、节奏快、规格常变"——JD 里"结果导向、多项目并行"不是套话,是真实状态
- **首个数采硬件规模化落地** = 行业没有现成的"数采交付标准",谁先建出 SOP/质检/SLA 体系谁就是行业标杆——JD 里"从 0 到 1 搭建交付流程体系"是公司当前最痛的点
- **A 轮投后重点含"真机评测闭环"** = 交付不止到"数据给客户",还要管"客户模型效果回流"——交付经理的闭环意识会直接对应公司战略

**一句话总结:公司正处在"订单爆发 + 体系缺位"的扩张期,资深交付经理就是去当"把生产交付体系建起来"的那个人。**
