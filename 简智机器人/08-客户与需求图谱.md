## 二、客户分五类,需求各不相同

### ① 具身智能模型公司(主力客户,如蚂蚁灵波、星海图)
**要什么**:大规模人类原生数据做 **VLA / 具身大模型预训练**——特别要**完整 CoT 推理链路**(人怎么想)、**触觉力觉**(手上的感觉)、**场景多样性**(泛化能力)。
**怎么买**:定制采集项目(指定场景+技能+时长)或持续数据协同(按模型版本迭代持续供给)。
**在意的点**:数据密度高不高、CoT 链路完不完整、供给稳不稳定。

### ② 世界模型公司
**要什么**:海量真实世界**多视角 Ego 视频+状态数据**,训练"预测物理世界"的模型。
**怎么买**:大容量标准化数据集 + 定制场景补充。

### ③ 机器人本体厂商
**要什么**:技能数据适配自家本体(如双臂/五指),少量遥操作数据做微调;以及**真机评测验证**(A 轮后简智的重点方向,大规模真机集群)。
**怎么买**:定制项目 + 评测服务。

### ④ 感知硬件/平台公司(如速腾聚创)
**要什么**:不是纯买数据,是**共建数据体系**——把速腾的三维感知硬件(深度/位姿/空间结构)与简智的采集生产真值能力融合,做"数据获取→治理→训练→应用验证"全链路。
**怎么买**:战略合作/联合方案,面向共同的下游客户。

### ⑤ 数采硬件客户(高校/研究所/其他数据团队/自建数采线的具身公司)
**要什么**:直接买 **Gen DAS 设备**(万台订单的主要构成)+ 配套使用培训、采集 SOP、平台工具。
**怎么买**:硬件销售 + 交付支持(这本身也是一类"交付"——设备交付)。

## 三、需求类型 → 简智产品 → 你的项目形态

| 客户需求 | 对应简智产品 | 交付经理的项目形态 |
|---|---|---|
| 预训练数据集采购 | 数据资产/开源集+定制 | **标准化数据包交付**(周期短,规格谈定即生产) |
| 定制场景/技能采集 | GenADP 产线 + Gen DAS | **定制采集项目**(像 07 沙盘:方案→样批→量产→验收) |
| 持续数据协同 | 数据协同框架(蚂蚁灵波模式) | **框架合同+滚动排产**(按模型版本节奏分批供数,长期项目管理) |
| 真值/标注加工 | DFM + 人工校验 | **数据加工服务项目**(客户给原始数据或粗数据) |
| 真机评测验证 | 真机评测集群 | **评测服务项目**(新方向,A 轮重点) |
| 买设备自建数采 | Gen DAS + Gen Matrix | **设备交付项目**(设备+培训+SOP+平台开通) |
| 共建数据体系 | 速腾模式 | **联合项目/生态共建**(多方协调,边界管理) |

**交付经理的洞察**:客户需求 = 7 种项目形态,管理要点各不同——一次性定制项目重"规格冻结+按期交付",框架协同重"节奏匹配客户模型迭代",设备交付重"部署培训支持",共建项目重"边界与分工"。面试讲多项目并行时,可以点出"项目形态不同,管理侧重不同"这种分层认知。

## 四、行业风险认知(面试反问/体现深度的弹药)

i黑马在 Pre-A 报道里点过几个行业真问题,面试聊到时能接得住会加分:

1. **巨头自建**:特斯拉、英伟达等巨头倾向自建数据体系或收购,对第三方数据供应商的依赖度存在变数 → 反问可问:"简智客户的复购和长期协同粘性,靠什么构建?"(答案方向:数据飞轮里的历史数据资产+生产体系切换成本+真值能力)
2. **2026 行业洗牌**:机器人赛道从"都能融资"进入洗牌期,数据服务商绑定头部模型公司很重要 → 蚂蚁灵波、速腾两笔战略合作正是"卡位"
3. **智驾背景迁移**:核心团队来自 Momenta,智驾数据闭环经验能否迁移到操作精度要求更高的机器人场景 → 你面试讲的"迁移能力"叙事,恰好也是这家公司自己的叙事

## 五、面试金句(客户视角)

> "我看了简智的公开合作——蚂蚁灵波要的是带完整 CoT 的人类原生数据去驱动 LingBot 模型进化,速腾聚创是三维感知硬件+数据生产的体系共建,加上 30 余家头部企业客户。这说明简智的客户需求至少有五六种项目形态:一次性定制、框架协同、加工服务、设备交付、联合共建。交付经理要能针对不同形态配不同的管理打法——这也正是我 7 年里管过的项目类型:有千万级定制交付,有长期框架运营,有 0 到 1 的体系建设。"
