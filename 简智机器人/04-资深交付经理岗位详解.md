# 04 · 资深交付经理岗位详解

> 这个岗位到底干什么、一天长什么样、你的经验怎么接、入职 90 天怎么干

## 二、JD 拆解(4 大块)

### ① 数采交付项目统筹
- 统筹数据采集项目全周期(采集→生产→质检→交付),对进度/质量负责
- 保障量产项目稳定交付(数据量、质量、时间节点)
- 多项目并行、交付节奏快

### ② 交付流程体系搭建(从 0 到 1 / 优化)——差异化重点
- 从 0 到 1 搭建数采交付流程体系:SOP、质检标准、SLA、异常处理与复盘机制

### ③ 协调内外部资源
- 协调采集、标注、质检、运营等内外部团队,高效响应业务与客户需求

### ④ 方法论沉淀
- 沉淀数采交付方法与最佳实践,推动流程标准化与团队能力提升

JD 关键词原文:数据标注 / 团队管理 / PMP / 非技术项目管理 / 大数据项目管理 / 数据采集 / 具身;1-3 年+数据交付或生产管理;质量/项目/跨团队协调;结果导向多项目并行。加分:大数据/人工智能/智能硬件。

## 三、岗位的一天(具象化,面试脑中要有这个画面)

> **9:00** 站会:看 Gen Matrix 产能看板——昨天各场景采集量、废批率、标注积压、质检吞吐;两个项目设备冲突,协调 DAS 设备调配
> **10:00** 质检日报:某厨房场景批次真值准确率掉到 92%(阈值 95%)——拉标注组长+质检员过边界案例,发现新菜品类没在规范里,补判例、更新规范
> **11:30** 客户对接:客户中途改规格(新增"户外夜市"场景),评估影响:场景搭建 2 周+数采员培训 3 天+设备防水改装——给客户出变更方案与时间表
> **14:00** 排产:下月 3 个项目抢产能,按 SLA 优先级排产,瓶颈在动捕场地——错峰排
> **16:00** SOP:把上周"户外强光下 Ego 视角过曝"的处理经验写成规范条目,推给所有户外场景项目
> **17:00** 复盘会:上周某整批报废事故——根因是设备同步漂移未校准,落地两条措施:开机校准入 SOP、平台加自动校验卡点

**体感**:一半时间在管产线(产能/质量/异常),一半时间在建体系(SOP/规范/复盘),客户沟通占三成。

## 五、入职 90 天计划(面试反问/收尾时的加分弹药)

**第 1-30 天:摸清现场**
- 跟完一条完整产线:从客户需求→场景搭建→数采→清洗→标注→质检→交付,画出实际流程图(实际做的,不是制度写的)
- 摸清三类数据:各场景废批率、真值准确率分布、近 3 个月 SLA 达成与违约记录
- 和采集/标注/质检/运营组长各做 1v1,收集"最头疼的三件事"

**第 31-60 天:立规矩**
- 输出 V1 交付 SOP(采集作业规范、标注规范与边界判例库、质检标准与抽检方案、异常分级与响应机制)
- 选 1 个在产项目试点,跑通并对比指标(一次通过率、返工率)
- 把复盘机制跑起来:每周事故/异常复盘,产出进 SOP

**第 61-90 天:见结果**
- 试点项目指标对比汇报:一次通过率、返工率、单小时成本的变化
- SOP V2(吸收试点反馈),开始横向复制到其他项目
- 建立产能/质量/交付三张周报看板,让管理层和客户都能看

**面试讲法**:"如果我入职,前 30 天我不动体系,先跟产线把真实流程和真实数据摸清;60 天出一个试点跑通的 V1 体系;90 天拿指标对比说话。体系要从实际中来,不能拍脑袋写文档。"

## 六、可能被问 + 应答要点

1. **你做过数据生产/交付吗?** → 迪士尼数据中台(量化:4 业务线、10 报表、提速 2h、省 300 万、人力省 50%)
2. **怎么从 0 到 1 搭交付流程体系?** → 先跟产线摸实情 → 立规范(SOP/质检标准/SLA)→ 试点验证 → 指标对比 → 横向复制(用 90 天计划讲)
3. **数据质量怎么把控?** → 三级质检(自检/互检/专检)+ 质检指标(准确率/完整性/一致性/规格)+ 不合格闭环(原因归类进 SOP)
4. **多项目并行怎么管?** → SLA 优先级排产、资源瓶颈识别(设备/场地/人力)、里程碑+周报、变更管理(讲迪士尼/同盾案例)
5. **没做过数采标注怎么办?** → gap 应对话术(上节)
6. **客户中途改规格怎么办?** → 影响评估(场景/人力/设备/工期)→ 变更方案+时间表 → 样批确认再批量(讲一次真实变更案例)
